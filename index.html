How the full automated version would work

A production version can regularly ingest authorised job feeds, normalise titles and bands, remove duplicates, check closing dates, and provide email alerts. NHS Jobs publishes integration guidance, including an XML/RSS self-serve feed; use of any other job-board data should follow its access and licensing terms. This version includes a live API backend that requires credentials and hosting.
